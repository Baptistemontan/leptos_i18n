# Contributing to Leptos i18n

Thanks for your interest in contributing! Issues and pull requests are welcome.

## AI-assisted contributions

Using AI tools to write code is accepted, under two conditions:

- **Disclose it.** If AI was used, there must be a trace of it: either mark the commits with a trailer such as
  `Co-authored-by:` or `Assisted-by:`, or simply mention it in the pull request.
- **You are responsible for the code.** You must understand everything you submit, be able to explain it, and have
  tested it. "The AI wrote it" is not an answer to a review comment.

**AI must not be used in discussions.** Issues, pull request descriptions, review replies and comments must be written by you.
When your code is reviewed, answer the review yourself, not with a generated response.
Short, imperfect English is completely fine.

AI generated commit messages are accepted though, as they describe the code, not a discussion.

Contributions that don't follow these rules may be closed without review.
